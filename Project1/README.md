# Project 1 - Static Routing & Network Services

## Overview

This project demonstrates the implementation of two interconnected networks using Cisco Packet Tracer.

## Features

* IP subnetting based on 192.168.0.0/24
* DHCP server configuration
* DNS server configuration
* HTTP server configuration
* Wireless Access Point setup
* Static Routing between routers
* End devices receiving IP addresses dynamically
