# Network+ Labs

A collection of Cisco Packet Tracer projects completed as part of Network+ training.

## Technologies

* Cisco Packet Tracer
* DHCP
* DNS
* HTTP
* Static Routing
* VLAN
* Subnetting

## Project 1 - Static Routing & Network Services

### Features

* IP subnetting using 192.168.0.0/24
* DHCP configuration
* DNS configuration
* HTTP server setup
* Wireless access point configuration
* Static routing between two networks

## Project 2 - VLAN Segmentation

### Features

* VLAN 10, 20 and 30 implementation
* Switch configuration
* Network segmentation
* Host communication within the same VLAN
* Subnet planning using 192.168.10.0/24
