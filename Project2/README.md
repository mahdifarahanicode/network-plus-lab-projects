# Project 2 - VLAN Segmentation

## Overview

This project demonstrates network segmentation using VLANs in Cisco Packet Tracer.

## Features

* Creation of VLAN 10, VLAN 20 and VLAN 30
* Switch configuration
* Network isolation between VLANs
* Communication between hosts within the same VLAN
* Subnet allocation based on 192.168.10.0/24
